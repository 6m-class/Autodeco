Архитектура мода

text 
КЛАССЫ:
• DecoAlgorithm — статический класс с основным алгоритмом декорирования
• TowerCluster — структура данных для одной башни (кластера блоков)
• GridCell — ячейка occupancy-сетки (колонка X → набор занятых Y)

ХУКИ:
• $modify(EditorUI) — перехват init() для добавления кнопки "Deco"
• $modify(MenuLayer) — логирование загрузки мода

КЛЮЧЕВЫЕ МЕТОДЫ:
• filterSolidBlocks() — фильтрация солид-блоков из выделения
• buildOccupancyGrid() — построение сетки 30×30 юнитов
• clusterTowers() — BFS-кластеризация колонок в башни
• analyzeTower() — поиск вершин, ступеней, краёв башни
• spawnDecorations() — спавн декора с назначением color channels
• setupColorChannels() — настройка Ch20-Ch25 (magenta/purple/orange/cyan)

Алгоритм (7 шагов)

  1. Собрать выделенные GameObject*, отфильтровать солид-блоки
  2. Построить occupancy-сетку (шаг 30 юнитов)
  3. Кластеризовать колонки в башни (BFS)
  4. Найти вершину, края, ступени каждой башни
  5. Спавн декора: шпили, узлы, линии, окантовка
  6. Назначить color channels (чередование)
  7. Настроить Color Channels уровня (Ch20-Ch25)

Визуальный стиль

  • Тёмные силуэты башен со ступенчатыми краями
  • Неоновые светящиеся контуры (glow)
  • Многослойные треугольные шпили
  • Квадратные узлы-микросхемы на стенах
  • Линии-дорожки как печатная плата

📦 Подробная инструкция по компиляции

Перед началом
Для компиляции мода вам понадобится Windows 10/11, Visual Studio 2022 (с компонентами C++), CMake и Python 3. Весь процесс займёт ~15-30 минут при первой сборке.
1

Скачайте и установите Visual Studio 2022

Скачайте Visual Studio 2022 Community (бесплатно). При установке обязательно выберите:

  • ✅ «Разработка классических приложений на C++»
  • ✅ Windows 10/11 SDK
  • ✅ MSVC v143 (инструменты компиляции)

Установка занимает 10-20 минут (~8 ГБ).

2

Установите CMake

Скачайте CMake 3.21+ и установите. При установке выберите «Add CMake to system PATH».

powershell 
winget install Kitware.CMake

# Проверка
cmake --version
3

Установите Python 3 и Geode CLI

Скачайте Python 3.10+. При установке обязательно поставьте галочку «Add Python to PATH».

powershell 
pip install geode-cli

# Проверка
geode --version

Если pip не найден, попробуйте py -m pip install geode-cli

4

Скачайте код мода с GitHub

powershell 
# Через Github (рекомендуется)
https://github.com/6m-class/Autodeco/blob/main/AUTODECO.zip
5

🔨 Компиляция мода

Откройте PowerShell в папке geode-mod/ и выполните:

powershell 
cd geode-mod

# Запустите сборку (Geode CLI сам скачает SDK и скомпилирует)
geode build
Что произойдёт при первом запуске:
  • Geode CLI автоматически скачает Geode SDK (~50 МБ)
  • Скачает bindings для GD 2.2081
  • Сгенерирует файлы CMake
  • Запустит компиляцию через MSVC
  • Создаст файл build/NeonCyberCastleDeco.geode
Если возникли ошибки:
  • «CMake not found» — перезапустите PowerShell, проверьте PATH
  • «MSVC not found» — установите Visual Studio с компонентами C++
  • «Geode SDK not found» — выполните geode setup
  • Ошибки компиляции — покажите логи тому, кто будет помогать
6

Установите мод в Geometry Dash

powershell 
# Автоматическая установка
geode install ./build/NeonCyberCastleDeco.geode

# Или скопируйте файл вручную:
# Скопируйте NeonCyberCastleDeco.geode в:
# %APPDATA%/Geode/mods/

Известные ограничения

1

ID декоративных объектов

ID объектов (SPIKE_LARGE_ID = 3979, SQUARE_NODE_OUTER = 4097 и т.д.) являются приблизительными и могут не соответствовать реальным ID в GD 2.2081. Необходимо сверить их с официальным справочником.

Решение: Замените константы в DecoAlgorithm.hpp на корректные ID.

2

Система Undo

Полная интеграция с UndoObject API GD требует дополнительной работы. Ctrl+Z может не отменить весь декор за одно нажатие.

Решение: Использовать EditorUI::createUndoObjects() для регистрации изменений.

3

Производительность

Декорирование большого количества объектов (>2000) может занять время и создать тысячи объектов.

Решение: Настройка max-objects-warning позволяет контролировать лимит.

4

Цветовые каналы

Мод использует каналы 20-25. Если они заняты игроком, возможен конфликт цветов.

Решение: Проверять занятость через ColorActionStore.

5

Платформы

Код протестирован только на Windows GD 2.2081. Работа на macOS, Android, iOS не гарантирована.

Решение: Тестировать на каждой платформе отдельно.

Рекомендации по улучшению

  • Сверьте ID объектов с официальным справочником GD 2.2081
  • Реализуйте полную интеграцию с UndoObject API
  • Добавьте оптимизацию для больших уровней (batch-спавн)
  • Используйте свободные цветовые каналы (20+ уже заняты модом)
  • Тестируйте на разных платформах
